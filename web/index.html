Set up your local keys

  1. Get the MarketPulse project on the team laptop, then run pip install -r requirements.txt in its folder.
  2. Put each API key in its matching local file in that folder: gemapi.txt (Gemini) and elevenapi.txt (ElevenLabs) are needed for live listening and scoring.
  3. Add hostinger_url.txt with this site's URL and hostinger_token.txt with the site's private upload token. The local worker uses them to publish updates.
  4. For optional features, add fredapi.txt, socialcrawlapi.txt, backboardapi.txt, and tigerdb.txt. Venue credentials belong in kalshikey.txt with privkey.txt, or polymarketkey.txt with polymarketsecret.txt.
  5. Run python control_worker.py and return here. Start in Dry run mode.

Keep keys on the team laptop. Do not paste them into this page, upload them to the website, or commit them to Git. Auth0 sign-in does not supply local API keys. Another team needs its own isolated deployment and worker to use its own account.

How it works

1 · ListenElevenLabs Scribe v2 Realtime turns live audio into text, sentence by sentence.
2 · ScoreGemini rates each passage −1 (dovish) to +1 (hawkish), compared with this speaker's own past answers.
3 · DecideA z-score of ±2 or more is a surprise. Markets were picked before the speech, so there's no search delay.
4 · TradeKalshi + Polymarket orders within $10/order, $50/day limits and a kill switch.
0 · ContextFRED macro data and Bluesky/Reddit crowd sentiment frame each surprise.
5 · ProveEach call is hashed onto Solana, stored in Tiger Data, and remembered by Backboard.
